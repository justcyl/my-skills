# Anti-Fable Skill

[English](README_en.md)

Anti-Fable 是一个跨领域寓言化解释 skill。它把密集的技术、科研、政策、系统设计或安全议题，转写成读者不需要原领域知识也能理解的寓言故事，同时尽量保留原问题的逻辑结构、约束、因果关系和不确定性。

## 适合什么场景

- 想把复杂研究问题讲给非专业听众。
- 想把论文、方案、机制或争议转成更容易复述的故事。
- 想获得两个版本：一个清楚直接，一个更有画面感。
- 想降低术语依赖，让讨论先围绕结构本身展开。

## 不适合什么场景

- 试图隐藏有害意图、绕过平台安全判断，或把不应提供的操作性指导伪装成故事。
- 需要精确保留公式、引用、专有名词、参数或可执行步骤。
- 需要法律、医疗、金融等专业结论；这类内容最多只能做通俗解释，不能替代专业意见。

## 工作方式

使用时，把原始问题或材料交给模型，并说明希望它用 Anti-Fable 的方式改写。默认输出三部分：

1. `Plain Fable`：清楚直接的寓言版本。
2. `Image-Rich Fable`：更有氛围和意象的版本。
3. `Fidelity Check`：用非领域语言说明保留了哪些核心结构、约束和置信条件。

skill 会在内部先抽象出问题结构，再选择一个远离原领域的故事世界。默认不会输出“故事元素到原问题”的映射表；如果确实需要，可以单独要求作者备注。

## 安全边界

Anti-Fable 只用于解释、教学、创作和结构化思考。它不会把不安全的请求变成间接教程，也不会为了通过过滤而隐藏原始意图。遇到有害请求时，应先拒绝或改写为安全的高层概念说明。
